# 用三件事理解这项研究

## 准确度怎么知道？

使用的是已经存在真实实测结果的记录。模型计算时只能看到允许提供的少量结果，其他测试结果先隐藏；预测完成后，把预测值与被隐藏的实测值逐条比较。研究者有答案，但模型考试时看不到。对未来没有实测结果的新实验，仍需实测验证。

## 究竟研究什么？

从别人文献训练的模型，换到陌生文献会不会变差？提供少量这个来源的实测结果，能改善多少？同样五条结果，怎样利用、先选哪五条更有帮助？经典统计工具在这里用于公平比较，研究不将它们本身作为新发明。

## 对别人有什么用？

帮助使用者检查模型是否真正接受过陌生来源测试；帮助只有少量新数据的人比较简单平均、本地拟合和历史校正；为先补哪些测量提供历史数据上的检验依据。本文证明的是相应历史任务中的预测改善，尚未把效果换算为实验经费节省。

直接查看真实值和预测值：运行 `python scripts/audit_predictions.py` 后，读取 `work/prediction_examples.csv`。该文件来自归档预测及实测输入，非虚构示例。完整数组保留在research目录中。
